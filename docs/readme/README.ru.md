# cpp_uni_logger
Это простейшая бибилиотека, добавляющая возможность логгирования данных и визуально удобного отображения информации в консоли.

### Подключение библиотеки
Вы можете просто скопировать файлы из директорий **Include** и **Source** в ваш проект.

### Write message into terminal
Вы можете вывести информацию в консоль в удобном формате с быстрой визуальной идентификацией типа сообщения. Пример можно посмотреть в каталоге Test.
